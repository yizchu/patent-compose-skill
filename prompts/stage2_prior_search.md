# Stage 2: 项目成果查新

## 任务目标

通过国内外专利数据库，全面、准确地检索与本专利项目相关的现有技术，从而明确界定哪些技术特征已被现有技术公开，哪些才是本专利的实质性创新特征。然后基于检索结果，客观评估本专利是否具备足够的创造性高度，确定本专利最具技术价值和市场保护意义的重点技术特征。

## 工作流程

### Step 1：生成中英文检索词

**`Read`** `${输出目录}/materials/claim-tree-v1.json` 中的项目成果“权利要求树”，执行以下操作：
1. **分析权利要求树**：识别核心技术特征、关键技术术语和创新点
2. **提取中文检索词（最多8个）**：
   - 优先选择专业术语、技术名词、名动组合
   - 确保与本项目高度相关，避免过于宽泛的词汇
   - 不能太碎，也不要随意组合搭配
   - 不应是过长的句子，保持精炼
3. **提取英文检索词（最多8个）**：
   - 使用国际通用的技术术语和标准表达
   - 保持与中文检索词的语义对应
4. **输出格式**：将中英文检索词分别以JSON列表格式写入：
   - 中文：`${输出目录}/materials/keyword-cn.json`
   - 英文：`${输出目录}/materials/keyword-en.json`

### Step 2：执行数据库检索

运行检索脚本，自动从国内外数据库抓取相关专利的标题、权利要求和摘要信息：
```bash
python "${SKILL_DIR}/scripts/prior_search.py" <项目根目录>
```
**重要说明**：
- 该脚本使用 Playwright 自动化浏览器进行专利检索，运行时间较长
- **启动脚本后，立即退出当前执行，不要等待脚本完成**
- 向用户显示："✅ 专利检索脚本已启动，正在后台运行中。请耐心等待脚本执行完成，完成后回复'继续'以执行下一步。"
- 等待用户明确确认后，再继续执行 Step 3
- **切勿持续监控或等待脚本运行完成，这可能会导致检索被迫中断**

### Step 3：执行网络检索
调用 **`WebSearch`** 工具，从网络上搜索与本专利项目相关的公开技术，记录它们的技术特征和摘要信息并标注网站URL，写入 `${输出目录}/prior art/WebSearch-results.md`文件。

### Step 4：整理检索结果

Step2和Step3的检索全部完成后，**`Read`** `${输出目录}/prior art`下的**所有** JSON 文件（每个JSON文件对应一个检索词，记录了检索出的每个专利的权利要求和摘要信息）和`WebSearch-results.md`文件，进行汇总分析：

1. **阅读每个专利或技术的摘要和权利要求**，判断其与本项目成果的相似程度
2. **标注相关性等级**：
   - 🔴 **高度相关**：公开了本专利的核心技术方案
   - 🟡 **部分相关**：公开了本专利的部分技术特征
   - 🟢 **几乎无关**：技术方案差异较大

将结果汇总写入 `${输出目录}/materials/prior-art.md` 文件，按相关性等级降序排列，格式要求如下：

| 字段 | 要求 |
|------|------|
| **标题** | 专利或技术名称|
| **来源** | 仅当来源为网络时填写 |
| **相关性等级** | 🔴高度相关 / 🟡部分相关 / 🟢几乎无关 |
| **相似特征** | 仅当等级为🔴或🟡时填写，说明具体的相似点 |

### Step 5：生成查新报告
**`Read`** `${输出目录}/materials/disclosure-v1.md`和`${输出目录}/materials/claim-tree-v1.json`，基于 Step4 的检索结果（**`Read`** `${输出目录}/materials/prior-art.md`）和常识，**深入界定本专利项目的技术边界**，撰写结构化的查新报告，写入 `${输出目录}/materials/prior-art-report.md` 文件。

**核心任务**：
- **界定技术边界**：明确划分 现有技术已公开的技术特征 与 本专利独有的技术特征 。
- **评估创造性高度**：基于对比文件，客观判断本专利是否具备足够的创造性。
- **明确核心技术**：确定专利申请时需要重点撰写和布局的技术特征。

**报告结构要求**：

```markdown

## 三、专利法"三性"评估

### 3.1 新颖性评估（专利法第22条第2款）
> 新颖性：该发明不属于现有技术，也没有任何单位或个人就同样的发明在申请日以前向国务院专利行政部门提出过申请。

- **评估结论**：[具备/不具备] 新颖性
- **评估依据**：
  - 本专利的核心技术方案是否已被单篇对比文件完全公开
  - 是否存在抵触申请（申请在先、公开在后的专利申请）
  - 区别技术特征是否使本专利与现有技术产生实质性差异

### 3.2 创造性评估（专利法第22条第3款）
> 创造性：与现有技术相比，该发明具有突出的实质性特点和显著的进步。

**（1）突出的实质性特点判断**
- **评估结论**：[具备/不具备] 突出的实质性特点
- **判断方法**：采用"三步法"进行分析
  - **第一步：确定最接近的现有技术**
    - 最接近的对比文件：[专利或技术名]
    - 选择理由：[技术领域相同/技术问题相似/技术效果接近]

  - **第二步：确定区别特征和实际解决的技术问题**
    - 区别特征：[列出所有区别技术特征]
    - 实际解决的技术问题：[基于区别特征所能达到的技术效果确定]

  - **第三步：判断是否显而易见**
    - 对比文件是否给出技术启示：[是/否]
    - 本领域技术人员是否容易想到：[是/否]
    - 是否存在结合障碍：[如有，说明]

**（2）显著进步判断**
- **评估结论**：[具备/不具备] 显著进步
- **判断依据**：
  - 是否克服了现有技术的缺陷：[说明]
  - 是否提供了不同技术思路：[说明]
  - 是否代表技术发展趋势：[说明]

**（3）创造性辅助判断因素**
- **克服技术偏见**：[是否克服了本领域的技术偏见，如有请说明]
- **取得意外效果**：[是否取得了预料不到的技术效果，如有请说明]
- **长期需求**：[是否解决了人们一直渴望解决但未能解决的问题，如有请说明]

### 3.3 实用性评估（专利法第22条第4款）
> 实用性：该发明能够制造或者使用，并且能够产生积极效果。

- **评估结论**：[具备/不具备] 实用性
- **判断依据**：
  - 是否能够在产业上制造或使用：[说明]
  - 是否能够产生积极效果：[说明]
  - 是否符合自然规律：[说明]
```

**撰写要求**：

| 维度 | 要求 |
|------|------|
| **客观性** | 基于对比文件如实分析，不夸大本专利创新性，不贬低现有技术 |
| **精准性** | 技术特征对比要具体到技术细节，避免空泛描述 |
| **可操作性** | 核心技术布局要为后续专利撰写提供明确的撰写方向和权利要求策略 |
| **完整性** | 所有高度相关和部分相关对比文件必须逐一分析，不可遗漏 |

- ⚠️ 专属技术特征描述应聚焦于**技术方案本身**，而非技术效果或应用场景
- ⚠️ 已被现有技术公开的特征 与 本专利独有的技术特征 的划分要有理有据，每个特征必须引用具体对比文件
- ⚠️ 创造性评估要客观公正，既要指出优势，也要如实说明风险

## 关键要求
- **真实性原则**：所有分析必须严格基于项目的真实文件，不得凭空捏造或臆测不存在的技术方案
- **全面覆盖**：不能遗漏任何技术细节，只有明显属于行业常规实现的内容才可以省略
- **术语标准**：必须采用所属技术领域的通用技术术语，优先使用国家标准、行业标准规定的规范名词，以及国际专利分类表（IPC）中的标准技术术语。国家有统一规定的自然科学名词，应当采用官方统一术语；无官方规定的，可采用本领域约定俗成的表述，不得自行编造非通用词汇。禁止使用口头俗称、网络热词、行业黑话、非技术类表述替代专业术语。
- **通俗易懂**：用清晰直白的语言描述技术方案，确保非本领域技术人员也能理解，避免空泛赞美、营销口号、万能句式、结构模板、正确废话等具有“AI味”套话。
